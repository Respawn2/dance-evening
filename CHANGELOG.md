# Журнал изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено]

### Добавлено

- Конвейер проверок GitHub Actions: стиль Markdown (markdownlint-cli2), стиль YAML
  (yamllint), проверка документов — плейсхолдеры, ссылки, переводы строк
  (scripts/check_docs.py)
- Шаблон pull request с чек-листом самопроверки по DoD
- Документация конвейера: состав проверок, локальный запуск, настройка защиты
  main — docs/pipeline.md
- Раздел «Ветвление и слияние» в docs/process.md
- Единый стиль редакторов (.editorconfig) и переводов строк (.gitattributes)

### Изменено

- CHANGELOG.md переехал из docs/ в корень репозитория — обещание из 0.1.0
- Инструмент бэклога зафиксирован как Jira: фактическое состояние вместо
  GitHub Projects
- README: бейдж конвейера и раздел «Разработка»
- Заголовок docs/process.md: старое название проекта «Данс-вечер» заменено
  на «Вечера»
- Документы приведены к единым правилам стиля: таблицы, отступы списков,
  длины строк

## [0.1.0] — 2026-10-24

Базовое состояние проекта.

### Добавлено

- Предметная область выбрана и проверена по четырём требованиям
- Зафиксирован принцип: на танцполе продукта не существует
- Словарь предметной области: ведущий / ведомая
- Состав команды (один участник) и зоны ответственности
- Постановка проблемы, персоны, путь пользователя
- Карты пути клиента для обеих персон
- Карта пользовательских историй, бэклог MoSCoW
- Дорожная карта, план семестра, соло-процесс
