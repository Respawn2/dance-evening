# План семестра — «Вечера»

Планирование от скорости: один модуль курса — одна неделя работы. Задачи внутри
модулей не расписываю по дням — по методичке Гантт показывает порядок и
зависимости, а не обязательства по каждому дню.

Часть работ стартует параллельно, не дожидаясь полного завершения предыдущих:
конвейер репозитория начинается до финальной правки требований; каркас сервиса —
до закрытия моделирования; схема данных — до закрытия модели домена;
клиентское приложение — до завершения наблюдаемости. Перекрытия отмечены
датами старта.

Порядок модулей 03–08 приведён к программе курса (ЛР 2): проектирование
(модули 03–06) идёт **до первой строки кода**, каркас (модули 07–08) — после.
Перенумерация зафиксирована в CHANGELOG, версия 0.3.0.
