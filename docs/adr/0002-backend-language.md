# 2. Язык и каркас серверной части

- **Статус**: принято
- **Дата**: 2026-11-07
- **Участники**: вся команда (1 человек)

## Контекст

Нужен язык серверной части на весь семестр. Язык задан кафедрой на поток
(ограничение `C-01`); запись всё равно нужна: она фиксирует, подходит ли язык
проекту, что из выбора следует и при каком условии к решению вернутся.
К ЛР 4 потребуются работа с базой, описание контракта API и проверка входных
данных; это первый опыт серверной разработки, полученный на этом курсе.

## Движущие факторы

- `C-04`: команда из одного человека, один семестр — объём, который реально
  освоить в одиночку, важнее скорости исполнения
- `NFR-05`: полный прогон тестов не дольше 60 секунд — язык с быстрым
  запуском и лёгкими тестами
- `FR-01`–`FR-09`: контракт API понадобится в ЛР 4Б — предпочтителен каркас,
  формирующий описание OpenAPI из моделей данных сам
- `NFR-01`: 95 % запросов быстрее 300 мс при 200 вечерах — **не различает
  варианты**: при таком объёме данных подходят все три

## Рассмотренные варианты

| Вариант | За | Против |
| --- | --- | --- |
| **Python 3.13 + FastAPI** | Проверка данных и описание API из коробки (`pydantic`); низкий порог входа; язык знаком с первого курса | Скорость исполнения ниже; ошибки типов ловятся отдельным инструментом (`mypy`) |
| Go + net/http | Высокая скорость; статическая типизация; единый исполняемый файл | Многословнее; описание API и проверка данных пишутся руками |
| C# + ASP.NET Core | Сильная платформа; развитая среда | Тяжелее окружение; привычнее коллегам по потоку, но не автору проекта |

## Решение

**Python 3.13 + FastAPI.** Определяющий довод — объём, который один участник
успевает освоить за семестр (`C-04`): проверка данных, описание API и
внедрение зависимостей даются каркасом, а не пишутся самостоятельно.

## Последствия

**Положительные.** Модели `pydantic` переиспользуются как проверка данных
и как описание OpenAPI (ЛР 4Б). Асинхронность доступна без дополнительных
библиотек (ЛР 6А, обработчик событий).

**Отрицательные.** Проверка типов — отдельный этап конвейера (`mypy`); без
него аннотации остаются документацией. Для задач, чувствительных к скорости
исполнения, язык не подошёл бы — в объёме курса такие задачи не возникают.

**Что пересмотрит решение.** Требование обрабатывать десятки тысяч запросов
в секунду на одном экземпляре, либо необходимость поставлять систему единым
исполняемым файлом без среды исполнения.
