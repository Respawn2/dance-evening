## Что считается архитектурным решением

Решение, которое затрагивает несколько частей системы, трудно обратимо либо
влияет на атрибуты качества. Остальное решается в коде и в саморевью.

## Как добавить запись

1. Взять следующий свободный номер (номера не переиспользуются)
2. Скопировать форму из [../templates/adr.md](../templates/adr.md)
3. Заполнить; раздел альтернатив — не менее двух вариантов с реальными
   доводами за и против
4. Добавить строку в эту таблицу
5. Отправить запросом на слияние; запись проходит саморевью по DoD
   из [../process.md](../process.md)

Конвейер проверяет обязательные разделы каждой записи и её наличие
в этом указателе (задание «Записи о решениях», состав —
в [../pipeline.md](../pipeline.md)).
