# Данс-вечер

Платформа танцевальных вечеров для города: единая афиша, запись с указанием роли
и видимый баланс ведущих и ведомых с динамической ценой на дефицитную роль.

Учебный проект по дисциплине «Технологии разработки программных систем»
(ОмГТУ, 09.03.01). Выполняется в одиночку, по облегчённому процессу.

## Принцип

Система не существует на танцполе. Всё взаимодействие — до входа и после выхода.
